# Контракт інтерфейсу: Діаграма станів (`docs/state.mmd`)

**Feature**: `001-uml-domain-model` | **Цільовий артефакт**: `docs/state.mmd`  
**Формат**: Mermaid (`stateDiagram-v2`) | **Кодування**: UTF-8 (без BOM)

---

## 1. Загальні вимоги до синтаксису Mermaid

1. Файл починається з ключового слова `stateDiagram-v2`.
2. Обов'язкова наявність явно вираженого початкового стану `[*]`.
3. Обов'язкова наявність кінцевих станів `[*]`, що позначають успішний випуск або зупинку/відмову (FR-015).
4. Переходи між станами повинні містити зрозумілі підписи подій та умов українською мовою.

---

## 2. Специфікація станів системи

| Ідентифікатор стану | Назва / Опис стану | Тип стану | Подія входу / Активність |
|---|---|---|---|
| `[*] (Initial)` | Початковий стан | Початковий | Ініціація процесу оформлення |
| `DocumentsReceived` | Пакет документів отримано | Робочий | Імпортер передав товаросупровідні документи брокеру |
| `DeclarationDrafting` | Формування проекту декларації | Робочий | Брокер вносить відомості, класифікує товари за УКТЗЕД |
| `DeclarationVerified` | Декларацію перевірено брокером | Робочий | Документи та коди перевірено, декларація готова до подання |
| `InspectionAssigned` | Призначено митний контроль | Робочий | Інспектор проводить документальний контроль або огляд |
| `DutiesCalculatedAndPaid` | Мито розраховано та сплачено | Робочий | Проведено нарахування за ставкою та підтверджено сплата |
| `CargoReleased` | Вантаж випущено у вільний обіг | Успішний термінальний | Інспектор проставив відмітку про випуск товару |
| `Rejected` | Оформлення відхилено / зупинено | Термінальний відмови | Виявлено невідповідності, контрабанду або несплату |
| `[*] (Final)` | Завершення життєвого циклу | Кінцевий | Закриття процедури митного оформлення |

---

## 3. Специфікація переходів (Transitions & Triggers)

1. `[*] --> DocumentsReceived : Подання пакета товаросупровідних документів (submitDocuments)`
2. `DocumentsReceived --> DeclarationDrafting : Пакет прийнято в обробку (processDocumentPackage = true)`
3. `DocumentsReceived --> Rejected : Пакет некомплектний або фіктивний (processDocumentPackage = false)`
4. `DeclarationDrafting --> DeclarationVerified : Успішна класифікація товарів та перевірка кодів (validateCommodityCodes)`
5. `DeclarationDrafting --> Rejected : Код товару заблоковано або не знайдено`
6. `DeclarationVerified --> InspectionAssigned : Подання декларації на митний пост (submitDeclaration)`
7. `InspectionAssigned --> DutiesCalculatedAndPaid : Митний контроль пройдено успішно (verifyDocuments = true)`
8. `InspectionAssigned --> Rejected : Виявлено порушення митних правил / контрабанду`
9. `DutiesCalculatedAndPaid --> CargoReleased : Митні платежі надійшли у повному обсязі (markDutiesPaid)`
10. `DutiesCalculatedAndPaid --> Rejected : Несплата платежів у встановлений термін`
11. `CargoReleased --> [*] : Товар оформлено та передано вантажоодержувачу`
12. `Rejected --> [*] : Складено протокол про порушення / оформлено повернення товару`
